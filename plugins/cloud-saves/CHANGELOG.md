# 更新日志

## v1.1.0 — 全面优化

### 🐛 Bug 修复（均经真实 Git 仓库实验验证）

- **存档列表幽灵标签**：`listSaves` 的 `git fetch --prune-tags` 缺少 `--prune`，导致"远程已删除、本地残留"的存档永远显示在列表中。已补齐参数，多设备删除后其他设备会同步清理。
- **删除仅存于远程的存档报错**：`deleteSave` 中 `git tag -d` 对不存在的本地标签直接抛异常（与注释意图相反），导致这类存档无法删除。现已容错处理并继续删除远程标签。
- **自动存档定时器静默失效**：`setupBackendAutoSaveTimer` 对 `const` 变量重复赋值，当间隔小于 1 分钟（如 0.5，旧校验允许）时抛 `TypeError`，定时器永远无法启动且用户无感知。已改为 `let`，并在 `POST /config` 将间隔校验收紧为 ≥ 1。
- **回档后游离 HEAD**：加载存档后仓库停留在 detached HEAD，后续新存档的提交游离在分支之外。现改为 `git checkout -B <分支> <存档提交>`，本地分支直接指向存档点；分支推送遇非快进时用 `--force-with-lease` 自动重试（存档以标签为准，`--force-with-lease` 仍会拒绝覆盖未察觉的远程新提交）。

### 🔒 安全加固

- **XSS 防护**：存档卡片、Toast 通知、差异文件列表、状态栏等处此前直接用 `innerHTML` 拼接存档名/描述/操作人（来自远程 Git 标签，共享仓库时他人可控）。现已全部经 `esc()` 转义后插入，`data-*` 属性同步转义，选择器使用 `CSS.escape`。
- **令牌清除**：新增"清除令牌"按钮（令牌输入框旁）。此前"断开连接"后令牌仍明文留在 `config.json`。
- **Git 超时保护**：所有 Git 调用统一 5 分钟超时（simple-git `timeout.block`），网络卡死不再导致 `currentOperation` 永久锁死整个插件（此前所有接口会一直返回 409）。

### 🧹 代码质量

- **移除 node-fetch 依赖**：Node 18+ 自带全局 fetch（SillyTavern 本身要求 Node 18+），删除约 30 行动态 import 与降级代码，并在 `package.json` 声明 `engines.node >= 18`。
- **覆盖逻辑去重**：手动"覆盖存档"与定时自动存档共用新的 `overwriteTagAtHead()`，消除约 70 行重复代码。
- **data 目录定位加固**：不再依赖 `process.cwd()`，优先按插件安装位置（`<ST根目录>/plugins/cloud-saves`）推断，兼容 systemd 等非标准启动方式。
- **配置原子写入**：`config.json` 先写临时文件再 rename，避免写入中断导致配置损坏。
- **清理死代码**：删除未被引用的 `configureRemote()`、`hasUnsavedChanges()`、未使用的 `crypto` 导入、未使用的 `style.css`（页面全部使用内联样式）、遗留的 `// TODO` 与 `[DEBUG]` 日志。
- **隐式全局变量**：`getSaveDiff` 中未声明的 `changedFiles` 已修正。
- **`.gitkeep` 降噪**：初始化时不再向 `_uploads`/`_cache` 等 Git 忽略目录生成 `.gitkeep`。

### ✨ 功能增强

- **自动存档结果可见**：`/status` 新增 `lastAutoSave` 字段，状态栏显示最近一次自动存档的成功/失败与时间（此前失败只写控制台）。
- **自动存档目标改为下拉框**：从存档列表选择要覆盖的存档，不再手输标签名（输错即静默失败）。
- **授权流程简化**：输入新令牌后直接点"授权并连接"即可，前端自动先保存配置，无需再手动点"配置"。
- **状态栏显示存档名**：当前存档从 base64 标签名解码为可读名称（浏览器端）。
- **存档列表**：搜索框 250ms 防抖；刷新列表后保留搜索/排序条件；每条存档返回并显示对应的提交哈希。
- **存档名称校验**：后端拒绝空白与超过 100 字符的名称，前端输入框同步限制。
- **更新检查地址可配置**：从 `package.json` 的 `repository` 字段读取上游地址（fork 用户修改该字段即可），并归一化比较（兼容 `.git` 后缀、`git+` 前缀）。

### ⚠️ 行为变更提示

- 加载存档后本地分支会指向存档提交（此前是游离 HEAD）；下次推送分支时若远程分支领先，会自动以 `--force-with-lease` 方式推送。
- 列表刷新会真正清理本地陈旧标签（`--prune-tags --prune`），本地自建且未推送到远程的标签也会被清理（本插件只管理 `save_*` 标签，一般无影响）。
